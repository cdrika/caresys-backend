# CareSys User Guides

## Agency owner onboarding

[Open the Word guide](CareSys_Agency_Owner_User_Guide_Account_Creation_to_Subscription_29_October_2026.docx)

Title: CareSys Agency Owner User Guide From Account Creation to Subscription. Version 1.0, 29 October 2026.

The 14-page guide covers personal login, sign-in, agency registration, required and optional contact details, administrator verification notifications, Stripe card setup and confirmation, package defaults, worker coverage, module selection, invoice download, workspace access and payment approval after trial expiry. It includes 15 screenshot figures and previews, a package comparison and troubleshooting guidance.

Screenshot source files and readable crops are in screenshots/Agency Onboarding. All account and agency details shown are fictional demonstration data. Registration screens were captured from the current local application with a disposable account. Billing stages and the invoice preview were produced with the application views and an isolated test database. The approval-notification example comes from the existing registration test evidence; the empty Stripe-hosted card form was supplied during the test walkthrough. No secret-key screenshot is included.

The disposable account and agency were removed after capture, preserving other accounts and Stripe configuration. Word layout was exported using installed Microsoft Word because LibreOffice is unavailable. All 14 pages were rendered and visually checked; generated PDFs and page images remain in the ignored build/qa directory and are not guide deliverables.
